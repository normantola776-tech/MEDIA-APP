☆MEDIA APP – MASTER SOFTWARE DEVELOPMENT PROMPT

PROJECT OVERVIEW

Develop a complete, production-oriented social media application named ☆MEDIA APP.

The application should provide a modern short-video social networking experience inspired by TikTok, while maintaining original branding, interface design, features and identity.

The platform must support Android and iPhone users. Anyone should be able to register, create a profile, upload videos, watch content, follow creators, communicate and participate in the community.

The application must also provide creator monetization, advertising, virtual gifts, subscriptions and an earnings management system.

Brand slogan: Create. Share. Connect. Earn.

Application name: ☆MEDIA APP

Target platforms:

- Android smartphones.
- Apple iPhones.
- Separate responsive web-based administrator dashboard.

- 1. BRANDING AND USER INTERFACE
- Create a professional brand identity for ☆MEDIA APP.
- Use a distinctive star-inspired logo.
- Brand colors:
- Black: #080808
- White: #FFFFFF
- Purple: #8B5CF6
- Pink: #FF2D75
- Charcoal: #151515
- Design requirements:
- Modern social media interface.
- Smooth animations.
- Premium typography.
- Attractive buttons and icons.
- Responsive layouts.
- Dark and light themes.
- Consistent design across all pages.
- Allow users to switch between dark mode, light mode and automatic system appearance.
- 2. USER AUTHENTICATION
- Implement complete registration and authentication.
- Features:
- Email registration.
- Password login.
- Google authentication.
- Apple authentication.
- Email verification.
- Password recovery.
- Unique usernames.
- Profile creation.
- Optional phone verification.
- Account deletion.
- Secure logout.
- Allow public registration.
- Include account roles:
- Normal user.
- Creator.
- Verified creator.
- Moderator.
- Administrator.
- Never allow users to assign themselves administrator privileges.
- 3. HOME VIDEO FEED
- Build a full-screen vertical video feed.
- The experience should include:
- 9:16 video playback.
- Vertical swipe navigation.
- Automatic video playback.
- Pause and play.
- Sound controls.
- Video captions.
- Creator information.
- Follow buttons.
- Like buttons.
- Comment buttons.
- Share buttons.
- Save video buttons.
- View counts.
- Create:
- For You feed.
- Following feed.
- Trending feed.
- Develop a recommendation system using user interests, engagement, video categories and viewing behaviour.
- Avoid repeatedly recommending the same content.
- 4. VIDEO CREATION AND UPLOAD
- Implement a complete video creation system.
- Allow users to:
- Record using their cameras.
- Upload from their galleries.
- Trim videos.
- Crop videos.
- Select thumbnails.
- Add descriptions.
- Add hashtags.
- Add captions.
- Add permitted audio.
- Save drafts.
- Preview videos.
- Publish videos.
- Delete videos.
- Support MP4 and MOV formats.
- Use efficient video compression, transcoding and streaming.
- Provide upload progress and error handling.
- 5. SOCIAL NETWORKING
- Implement:
- Likes and comments.
- Comment replies.
- Following and followers.
- User mentions.
- Hashtags.
- Video sharing.
- Saved videos.
- Creator profiles.
- Account blocking.
- Content reporting.
- Make interaction counts accurate and prevent duplicate likes and follows.
- 6. PRIVATE MESSAGING
- Develop a real-time messaging system.
- Features:
- Private conversations.
- Text messaging.
- Image sharing.
- Video sharing.
- Message timestamps.
- Read receipts.
- Online indicators.
- Push notifications.
- Conversation blocking.
- Message reporting.
- Implement proper privacy permissions so only authorized participants can read conversations.
- 7. EXPLORE AND DISCOVERY
- Build a discovery page with:
- Trending videos.
- Popular creators.
- Trending hashtags.
- Search functionality.
- Music and audio discovery.
- Video categories.
- Recommended accounts.
- Include regional discovery, particularly content popular in Uganda and East Africa.
- 8. CREATOR STUDIO
- Create a dedicated creator dashboard.
- Show:
- Total video views.
- Total followers.
- Total likes.
- Engagement rate.
- Video performance.
- Audience insights.
- Earnings statistics.
- Published videos.
- Draft videos.
- Allow eligible creators to manage their content and monetization settings.
- 9. CREATOR MONETIZATION
- Implement a complete monetization infrastructure.
- Revenue sources:
- A. Video rewards:
- Allow eligible creators to earn from qualifying video views and engagement according to programme rules.
- B. Virtual gifts:
- Allow users to purchase virtual gifts and send them to creators.
- C. LIVE gifts:
- Allow viewers to send virtual gifts during broadcasts.
- D. Subscriptions:
- Allow fans to subscribe to eligible creators for exclusive content.
- E. Advertising:
- Provide advertising placements and campaign management.
- F. Brand partnerships:
- Allow approved brands and creators to collaborate.
- Create an earnings centre displaying:
- Lifetime earnings.
- Available balance.
- Pending balance.
- Gift earnings.
- Subscription earnings.
- Advertising earnings.
- Transaction history.
- Withdrawal history.
- Implement:
- Secure financial ledger.
- Verified payment transactions.
- Fraud detection.
- Withdrawal requests.
- Minimum payout thresholds.
- Creator eligibility rules.
- Administrative financial oversight.
- Integrate compliant payment providers for the supported countries.
- Include mobile money payout support where providers and applicable regulations permit, particularly for Uganda.
- Implement Apple and Google in-app purchase requirements for digital goods and subscriptions where applicable.
- Never award financial balances based solely on unverified client-side activity.
- 10. LIVE STREAMING
- Implement live video broadcasting.
- Features:
- Start live streams.
- Join live broadcasts.
- Real-time comments.
- Viewer counts.
- Reactions.
- Virtual gifts.
- Moderator controls.
- Stream reporting.
- Eligibility restrictions.
- Use a scalable real-time video streaming provider.
- Provide safety controls and moderation before enabling live streaming publicly.
- 11. NOTIFICATIONS
- Create notifications for:
- New followers.
- Likes.
- Comments.
- Replies.
- Mentions.
- Private messages.
- Live broadcasts.
- Creator earnings.
- Subscription activity.
- Include unread indicators and notification settings.
- 12. USER PROFILES
- Every profile should display:
- Profile picture.
- Username.
- Display name.
- Biography.
- Followers.
- Following.
- Total likes.
- Uploaded videos.
- Saved videos.
- Follow button.
- Edit profile.
- Share profile.
- Support public and private accounts.
- 13. ADMINISTRATOR DASHBOARD
- Develop a separate secure web administration portal.
- Features:
- User management.
- Video moderation.
- Comment moderation.
- Reports management.
- Account verification.
- Account suspensions.
- Transaction monitoring.
- Creator monetization management.
- Advertising management.
- Platform analytics.
- System configuration.
- Include role-based administrator permissions and audit logs.

- Create a scalable database with collections or equivalent relational tables for:
- users

- Use proper indexes, pagination and secure database rules.
- 15. SECURITY AND CONTENT MODERATION
- Implement:
- Secure authentication.
- Database access restrictions.
- File upload validation.
- Rate limiting.
- Spam protection.
- Fraud detection.
- Content reporting.
- User blocking.
- Copyright protection.
- Privacy controls.
- Account security.
- Secure financial transactions.
- Include community guidelines, privacy policy and terms of service.
- Provide appropriate age restrictions and safety measures.
- 16. PERFORMANCE
- Optimize the application for mobile networks, including slower internet connections.
- Implement:
- Lazy loading.
- Video caching.
- Image optimization.
- Adaptive video quality.
- Pagination.
- Efficient database queries.
- Background upload handling.
- Error recovery.
- Network connectivity detection.
- Make the interface responsive and smooth.
- 17. APPLICATION NAVIGATION
- Create five main bottom navigation items:
- HOME – Video feed.
- EXPLORE – Search and discover.
- CREATE – Upload and record.
- INBOX – Messages and notifications.
- PROFILE – Account and creator dashboard.
- Place additional features in appropriate secondary pages.
- 18. TESTING AND QUALITY ASSURANCE
- Test the complete application on Android and iOS.
- Test:
- Registration and login.
- Video uploads.
- Video playback.
- Likes and comments.
- Following.
- Messaging.
- Notifications.
- Payment verification.
- Creator earnings.
- Withdrawal requests.
- Privacy settings.
- Administrator functions.
- Fix broken buttons, navigation errors, crashes and database problems.
- Do not use fake success messages or simulated transactions in production.
- 19. DEPLOYMENT
- Prepare the application for:
- Google Play Store.
- Apple App Store.
- Firebase backend deployment.
- Administrator dashboard hosting.
- Provide:
- Android production build.
- iOS production build.
- App icons.
- Splash screen.
- Store screenshots.
- Application description.
- Privacy documentation.
- Release configuration.
- 20. FINAL DELIVERY REQUIREMENT
- Deliver a fully connected and functional ☆MEDIA APP.
- Do not build only a static prototype.
- Every major feature must have a working frontend and backend.
- Use real authentication, persistent data storage, actual video uploads, real-time interactions and verified payment processing.
- Where an external provider or account connection is required, build the integration interface and clearly identify the configuration required.
- Develop in manageable stages, test each stage and fix errors before moving to the next.
- The final product must be professional, secure, scalable and ready for app-store submission after the required testing, compliance checks and production configuration.
